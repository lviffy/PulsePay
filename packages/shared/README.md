# @pulsepay/shared

Shared schemas, TypeScript types, and constants for PulsePay.

## Installation

```bash
npm install @pulsepay/shared zod
# or
pnpm add @pulsepay/shared zod
```

## Features

- Shared Zod validation schemas for invoices, receipts, and subscriptions
- Canonical status enums and type definitions
- CSV ledger export formatters
