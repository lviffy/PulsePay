# @pulsepay/adapter-hedera

Hedera Agent Kit v4 spend policy, HCS audit topic hook, and x402 payment adapter for PulsePay.

## Installation

```bash
npm install @pulsepay/adapter-hedera @hashgraph/hedera-agent-kit @hiero-ledger/sdk viem zod
# or
pnpm add @pulsepay/adapter-hedera @hashgraph/hedera-agent-kit @hiero-ledger/sdk viem zod
```

## Features

- **Spend Limit Policies**: Enforce maximum spend per transaction and daily limits for autonomous AI agents.
- **HCS Audit Hook**: Log verifiable onchain payment audit trails to Hedera Consensus Service.
- **Hedera EVM Invoicing**: Direct integration with Hedera EVM merchant hub smart contracts.
