# @pulsepay/adapter-uniswap

Uniswap Trading API routing for universal multi-token checkout and Uniswap v4 treasury management.

## Installation

```bash
npm install @pulsepay/adapter-uniswap viem
# or
pnpm add @pulsepay/adapter-uniswap viem
```

## Features

- Exact-output swap quote routing for buyer checkout in any ERC-20 token
- Uniswap v4 hook-based treasury rebalancing and fee tier automation
