# @pulsepay/adapter-whitechain

Whitechain EVM client, contract ABI bindings, and indexer for PulsePay MerchantHub.

## Installation

```bash
npm install @pulsepay/adapter-whitechain viem
# or
pnpm add @pulsepay/adapter-whitechain viem
```

## Features

- Complete ABI types and encodings for `PulsePayMerchantHub`
- Public and Wallet viem client bindings for Whitechain Testnet & Mainnet
- Invoice lifecycle, payment reserve, and subscription execution functions
